# chomp-game-python
This is a “Chomp” game implemented in Python.   You can play against the computer using MIN-MAX search.

Pythonで実装した「チョンプ（Chomp）」ゲームです。  MINMAX探索を用いたコンピュータ対戦ができます。

## ゲーム概要

チョンプは、毒入りチョコを避けながら交互にチョコを食べるゲームです。

## ルール

- プレイヤーは交互にチョコを選択します。
- 選択したチョコより右かつ下にあるチョコはすべて食べられます。
- 左上の「1」は毒入りチョコです。
- 毒入りチョコを食べたプレイヤーの負けです。

## 使用技術

- Python 3
- MINMAX探索
